# 🏘️ 마을 경제 시스템 시나리오 (Village Economy System Scenario)

## 📖 개요 (Overview)

**8BIT 마을**은 N/B 길드의 지점장인 **촌장**이 이끄는 독특한 경제 시스템을 가진 마을입니다. 마을 주민들은 각자의 역할과 전문성을 바탕으로 **실제 거래**와 **모의 거래**를 통해 마을 경제를 발전시키고, N/B 코인을 통해 학습하며 성장합니다.

---

## 🏛️ 촌장 시스템 (Mayor System)

### 촌장의 역할
- **마을 재정 관리**: N/B 길드의 지침에 따라 마을 경제를 관리
- **구역별 전략 공지**: 현재 시장 상황에 따른 구역별 전략 안내
- **주민 교육**: 각 주민의 학습과 성장을 지원

### 구역별 전략
```
🔵 BLUE 구역 (알파 구역)
- 매수세가 강함
- 공격적 전략 권장
- 신뢰도: 70%
- 권장 전략: BUY

🟠 ORANGE 구역 (베타 구역)  
- 베타적 관계 형성에 주의
- 빠른 수익 실현 중요
- 신뢰도: 60%
- 권장 전략: SELL (신중하게)
```

### 공지 시스템
- **5분마다 자동 공지**: 현재 구역과 전략 안내
- **구역 변경 시 즉시 공지**: 시장 상황 변화 감지
- **실시간 가격 정보**: 현재 시장 가격과 함께 공지

## 👥 마을 주민 시스템 (Village Residents System)

### 주민 구성
1. **정찰병 (Scout)** - 탐험가
   - 위치: 게이트
   - 전문: 빠른 신호 감지
   - 트레이너 카드: minute1, minute3
   - 전략: 모멘텀

2. **후견인 (Guardian)** - 보호자
   - 위치: 시장
   - 전문: 추세 보호
   - 트레이너 카드: minute5, minute10
   - 전략: 평균 회귀

3. **분석가 (Analyst)** - 전략가
   - 위치: 타워
   - 전문: 전략적 분석
   - 트레이너 카드: minute15, minute30
   - 전략: 돌파

4. **어른 (Elder)** - 고문
   - 위치: 여관
   - 전문: 장기적 지혜
   - 트레이너 카드: minute60, day
   - 전략: 스캘핑

### 주민 특성
- **HP/체력**: 거래 활동으로 인한 피로도
- **스킬 레벨**: 경험과 성과에 따른 능력치
- **N/B 코인 잔액**: 개인 재정 상태
- **학습률**: 새로운 전략 습득 능력

## 💰 N/B 코인 경제 시스템 (N/B Coin Economy)

### 코인 획득
```
모의 거래 시작 시: +0.001 N/B 코인
실제 거래 시작 시: -0.001 N/B 코인 (사용)

수익 발생 시:
- 모의 거래: +수익률 × 거래량
- 실제 거래: +수익률 × 거래량 × 1.5 (50% 보너스)

손실 발생 시:
- 모의 거래: -손실률 × 거래량
- 실제 거래: -손실률 × 거래량 × 1.5 (50% 페널티)
```

### 코인 사용
- **실제 거래**: N/B 코인을 소모하여 실제 시장에 참여
- **학습 강화**: 코인 성과가 학습 모델에 반영
- **거래 빈도**: 코인 잔액에 따른 거래 활성도 조절

## 🎯 거래 판단 시스템 (Trading Decision System)

### 실제/모의 거래 판단 요소

#### 1. N/B 코인 잔액
```
> 0.01 코인: +30% 실제 거래 확률
> 0.005 코인: +20% 실제 거래 확률
> 0.001 코인: +10% 실제 거래 확률
< 0.001 코인: 모의 거래만 가능
```

#### 2. 스킬 레벨
```
Master (2.0+): +20% 실제 거래 확률
Expert (1.5+): +15% 실제 거래 확률
Advanced (1.2+): +10% 실제 거래 확률
Beginner (1.0): 기본 확률
```

#### 3. 승률
```
> 70%: +15% 실제 거래 확률
> 60%: +10% 실제 거래 확률
< 40%: 실제 거래 확률 감소
```

#### 4. 현재 구역
```
BLUE 구역: 기본 확률
ORANGE 구역: 50% 감소 (더 신중)
```

### 거래 타입 결정 예시
```
정찰병 (Scout) 거래 판단:
- N/B 코인: 0.008 (높음)
- 스킬 레벨: 1.8 (Expert)
- 승률: 75% (높음)
- 현재 구역: BLUE
- 실제 거래 확률: 10% + 20% + 15% = 45%
→ 45% 확률로 실제 거래 실행
```

## 📊 학습 시스템 (Learning System)

### 경험치 획득
```
모의 거래 성공: +수익 × 1000 경험치
모의 거래 실패: +손실 × 500 경험치
실제 거래 성공: +수익 × 1500 경험치 (50% 보너스)
실제 거래 실패: +손실 × 750 경험치 (50% 보너스)
```

### 스킬 레벨 향상
```
수익 발생 시: +수익 × 0.1 스킬 포인트
손실 발생 시: -손실 × 0.05 스킬 포인트
실제 거래: 50% 추가 보너스/페널티
```

### 전략 진화
```
높은 성과 달성 시: 10% 확률로 전략 변경
전략 옵션: momentum, meanrev, breakout, scalping
```

## 🔄 거래 사이클 (Trading Cycle)

### 1. 촌장 공지 단계
```
🏛️ 촌장 공지사항
📊 현재 구역: 🔵 BLUE | 현재가: 163,185,000
📢 🔵 BLUE 구역: 알파 구역으로 매수세가 강합니다. 신중하게 매수 전략을 실행하세요.
🎯 권장 전략: BUY | 신뢰도: 70%
```

### 2. 차트 분석 단계
```
각 주민이 자신의 트레이너 카드(시간대)에 맞는 차트 분석
- 정찰병: 1분, 3분 차트 분석
- 후견인: 5분, 10분 차트 분석
- 분석가: 15분, 30분 차트 분석
- 어른: 1시간, 일일 차트 분석
```

### 3. 거래 판단 단계
```
N/B 코인 잔액, 스킬 레벨, 승률, 구역을 종합하여
실제 거래 vs 모의 거래 결정
```

### 4. 전략 실행 단계
```
구역별 전략에 따른 매수/매도 실행
- BLUE 구역: BUY 우선
- ORANGE 구역: SELL 우선 (신중하게)
```

### 5. 결과 반영 단계
```
거래 결과를 N/B 코인과 학습 모델에 반영
성공/실패에 따른 경험치와 스킬 레벨 조정
```

## 📈 평균가 시스템 (Average Price System)

### 다중 거래 추적
```
1차 매수: 163,000,000에 0.001 BTC
2차 매수: 162,500,000에 0.001 BTC (추가)
평균가: 162,750,000
총 수량: 0.002 BTC
```

### 평균가 계산
```
평균가 = (가격1 × 수량1 + 가격2 × 수량2 + ...) ÷ 총 수량
```

### UI 표시
```
📊 BUY 0.002 @ 162,750,000 (평균가)
P&L: +0.15%
📈 평균가: 162,750,000 | 총 수량: 0.002000 BTC
```

## 🎮 시나리오 예시 (Scenario Example)

### 시나리오 1: BLUE 구역에서의 성공적인 거래
```
1. 촌장 공지: "🔵 BLUE 구역, 매수세 강함"
2. 정찰병 분석: 1분 차트에서 상승 신호 감지
3. 거래 판단: N/B 코인 0.012, 스킬 1.8 → 실제 거래 결정
4. 거래 실행: BUY 0.001 BTC @ 163,000,000
5. 결과: +2.5% 수익
6. 보상: +0.0000375 N/B 코인, +3750 경험치, 스킬 +0.0375
```

### 시나리오 2: ORANGE 구역에서의 신중한 거래
```
1. 촌장 공지: "🟠 ORANGE 구역, 빠른 수익 실현 중요"
2. 후견인 분석: 5분 차트에서 하락 신호 감지
3. 거래 판단: N/B 코인 0.003, 스킬 1.2 → 모의 거래 결정
4. 거래 실행: SELL 0.001 BTC @ 162,500,000
5. 결과: +1.8% 수익
6. 보상: +0.000018 N/B 코인, +1800 경험치, 스킬 +0.018
```

### 시나리오 3: 평균 다운 전략
```
1. 정찰병: 첫 번째 BUY @ 163,000,000
2. 가격 하락: 162,500,000으로 하락
3. 정찰병: 두 번째 BUY @ 162,500,000 (평균 다운)
4. 평균가: 162,750,000
5. 가격 회복: 163,200,000으로 상승
6. 결과: +0.28% 수익 (평균가 대비)
```
